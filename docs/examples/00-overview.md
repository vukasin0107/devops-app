# Examples

Real, runnable artifacts that back up the concepts: sample Terraform modules, a working
CI/CD pipeline YAML, a Dockerfile + Kubernetes manifest set, a monitoring stack config, etc.

Suggested structure once populated, one subfolder per example:

- `terraform-vpc/`
- `github-actions-pipeline/`
- `k8s-nginx-deployment/`
- `prometheus-grafana-stack/`

Each example folder should have its own short README explaining what it demonstrates and
which concept chapter(s) it supports.

> Not yet populated — add examples as each concept chapter matures.
